HOW TO RUN ON ANY PC (1-CLICK SETUP):
------------------------------------------------------------------------------
1. Ensure Python 3.10+ is installed on the PC (from https://www.python.org).
   Make sure "Add Python to PATH" is checked during installation.

2. Simply DOUBLE CLICK the file:
   👉 START_PROJECT.bat

3. The script will automatically:
   - Install all required packages (fastapi, uvicorn, jinja2, python-multipart)
   - Start the local web server on port 8000
   - Automatically open the portal in your default web browser at:
     http://127.0.0.1:8000
